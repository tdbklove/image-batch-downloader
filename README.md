# ImageBatchDownloader（頁面圖片批次下載）

Chrome Manifest V3 擴充功能：掃描目前分頁的圖片，以縮圖格狀清單勾選後批次下載。

## 支援的網站

- **Pixiv** 作品頁：下載所有頁的原圖
- **Postype** 文章：下載文章內的全部原圖
- **其他網頁**：列出頁面上的圖片

## 安裝

1. 開啟 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 選「載入未封裝項目」，選取本資料夾。
4. 前往要掃描的網頁，點擴充功能圖示並按「掃描目前頁面」。

修改程式碼後，回到擴充功能頁按重新載入即可；不需要重新整理已開啟的分頁（掃描腳本是按下掃描時才注入）。

## 使用

- **Shift + 點選**：一次勾選或取消一段範圍。
- 點 popup 左下角的存放位置（或擴充功能的「選項」）開啟設定頁。

設定頁的「掃描」區塊：

- **最小圖片尺寸**（預設 200 px）：長或寬小於此值的圖片不列出，用來濾掉頭像、圖示；尺寸未知的仍會列出。
- **自動捲動載入**（預設關閉）：掃描一般網頁前先捲到底，讓延遲載入的圖片出現。Pixiv、Postype 用專用轉接器，不需要也不受影響。

## 存放位置

| 模式 | 說明 |
| --- | --- |
| 瀏覽器的下載資料夾（預設） | 可再指定子資料夾，例如 `Art/插畫`。按下載後可以關閉 popup，下載會在背景繼續。要換下載資料夾本身，請改 Chrome 設定 › 下載。 |
| 自選資料夾 | 用資料夾選擇器挑任何位置（例如 `D:\圖片`），由 popup 直接寫入檔案。重開瀏覽器後第一次下載會再詢問一次寫入權限；寫入完成前請保持 popup 開啟。 |

開啟「依網站與作品自動分資料夾」時（預設開啟），會保留原始檔名並分資料夾：

- `pixiv/{作者}_{作者ID}/{作品ID}_{標題}/119997896_p0.png`
- `postype/{作者}/{文章ID}_{標題}/xxxx.jpg`
- `page-images/{網域}/xxxx.jpg`

同名檔案會自動改名為 `name (1).ext`。第一次批次下載時，Chrome 可能詢問是否允許多檔下載。

## 檔案

- `content.js`：掃描邏輯與各網站轉接器（`adapters` 陣列），新增網站時加在這裡。
- `shared.js`：popup、設定頁與 background 共用的設定存取、檔名清理與路徑規則；自選資料夾的 handle 存在 IndexedDB。
- `background.js`：存到下載資料夾時的下載佇列（同時 3 個），回報進度與失敗原因。
- `popup.js`：掃描介面；自選資料夾模式下也負責 fetch 並寫入檔案。
- `options.html` / `options.js`：設定頁。
- `icons/`：`icon.svg`（48、128 px）與簡化版 `icon-small.svg`（16、32 px）是原始檔，PNG 由它們輸出。
- `offscreen.html` / `offscreen.js`：需要 Referer 的圖片先在這裡 fetch 成 blob 再交給下載管理員。
- Referer：轉接器在圖片上標記 `referer`，`background.js` 會替該圖片網域加一條 declarativeNetRequest session 規則（只作用於擴充功能自己的請求，不影響一般瀏覽）。

## 目前限制

- Pixiv 只支援單一作品頁；使用者頁、排行榜等列表頁會退回一般掃描（只拿到縮圖）。動圖（ugoira）只會下載第一格。
- R-18 或限定公開作品需要先在瀏覽器登入 Pixiv。
- Postype 付費／限定內容需要已有閱讀權限。
- `blob:` / `data:` 圖片與 `<canvas>` 繪製的圖片會略過。
- 瀏覽器內部頁面（例如 `chrome://`、線上應用程式商店）不能掃描。
